# Hack and Slash Prototype

This repository contains a hack and slash prototype developed with **Unity 6000.3.25f1**.

Some of the code was generated using an LLM. No AI agents were used in the development of this project.

## Getting Started

1. Install **Unity 6000.3.25f1** using Unity Hub.
2. Clone or download this repository.
3. Open **Unity Hub**.
4. Click **Add** and select the project folder.
5. Open the project.
6. Open Scene: Assets -> Scenes -> Level0 
7. Click play. The prototype can be played with keyboard and mouse or gamepad.
